# Football Player Similarity & Recommendation Engine

An explainable machine-learning system that recommends football players with similar statistical and playing profiles.

## Project Status

🚧 Under development

## Planned Features

- Player search
- Position-aware player similarity
- Top-K player recommendations
- Cosine similarity
- KNN
- PCA
- Player clustering
- Explainable recommendations
- Player comparison
- Percentile statistics
- Radar charts
- Interactive Streamlit application

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Plotly
- Streamlit
